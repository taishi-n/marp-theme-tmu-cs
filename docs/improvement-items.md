# 対応範囲を指定するための項目一覧

繰り返された依頼の分類を，個別に採否を指定できる66項目へ分解した．
番号はこの一覧の固定識別子とし，今後の選択や計画変更でも振り直さない．
2026-11-05に全項目の対応が承認された．
33は引用の脚注のみ，文献一覧のみ，両方の3通りへ拡張し，37の章扉切り替えはAの機能として扱う．
詳しい理由と対応済み機能の扱いは[責務分担](improvement-ownership.md)にまとめた．

## 解決先の意味

- **A**: このrepoの機能自体の改善．依存先のwavegramとの統合も含む．
- **B**: `tmu-cs-lecture-slides`スキルの改善．共通の執筆方針，既存機能の使い方，作業手順を扱う．
- **C**: 個別repoでの策定．研究やデッキに固有の内容，定義，数値，構成を扱う．

66項目の主担当はAが12項目，Bが43項目，Cが11項目であり，重複なく割り当てた．
Aの49，56，57，58は対応する実装が既にあり，新規実装として繰り返す対象ではない．
既存設定で実現できる列配置，TeX，ページ番号，wavegramの表示指定などはBへ移した．
スキルの一般的な既定より，Cで定めた原稿や発表の方針を優先する．
この一覧は反復した大分類を分解したものであり，全66項目がそれぞれ複数セッションで依頼されたという意味ではない．
根拠欄の識別子は[根拠資料](improvement-evidence.json)の`requests`と`supplementary_requests`に対応する．
細分化のために追加確認した17件は，前回の大分類の件数には加えていない．
